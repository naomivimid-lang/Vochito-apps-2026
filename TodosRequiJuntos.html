Requerimientos no funcionales

Bochito: calidad, seguridad y disponibilidad para el comercio local.

Administración del sistema

Consulta las características que ayudan a mantener el sistema Bochito disponible, rápido, seguro y fácil de usar.

RNF03

Alta disponibilidad

El sistema deberá mantener una disponibilidad anual del 99.9%, de acuerdo con el objetivo establecido para el proyecto.

Objetivo de disponibilidad: 99.9%

Para alcanzar este objetivo se requiere supervisar el servicio, detectar fallos y contar con procedimientos de recuperación.

RNF04

Rendimiento

El sistema deberá responder a las solicitudes de los usuarios de manera oportuna, incluso cuando exista actividad simultánea.

Supervisión del tiempo de respuesta

Se deberán medir los tiempos de respuesta y realizar pruebas de rendimiento para identificar posibles retrasos.

RNF05

Seguridad

El sistema deberá proteger la información y permitir el acceso únicamente a usuarios debidamente autenticados y autorizados.

Protección de acceso e información

Se recomienda utilizar contraseñas protegidas, validación de datos, control de permisos y conexiones HTTPS.

RNF06

Usabilidad

La interfaz deberá ser clara, intuitiva y adaptable para facilitar la navegación y el uso de las funciones del sistema.

Interfaz adaptable y accesible

Se utilizarán etiquetas claras, navegación consistente, formularios comprensibles y diseño adaptable a distintos dispositivos.

Nota: los indicadores y las descripciones de esta página representan objetivos del proyecto. No son mediciones reales de disponibilidad, rendimiento o seguridad.
