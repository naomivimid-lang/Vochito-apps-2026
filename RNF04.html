Tolerancia a fallos (resiliencia)

Si se pierde la comunicación con las APIs de las empresas transportistas, el sistema encola las peticiones y las reintenta automáticamente sin perder datos.

Objetivo del requerimiento

Encolar las peticiones a las APIs de transportistas cuando falle la comunicación (con herramientas como Kafka o RabbitMQ) y reintentar la sincronización de estados automáticamente, sin pérdida de datos.

Esta página contiene una demostración local del mecanismo de reintento. No representa una conexión con un servidor real.
